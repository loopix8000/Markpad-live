# Changelog

Each release's notes are taken from its section here. Add a section for the new version before running the Build and Release workflow.

## 0.1.3

- Find in the editor matches text that crosses bold, italic and other formatting, highlights every match, shows how many there are, and has case and whole-word options. The find bar sits on the right and no longer hides behind the outline button.
- Double-clicking inline code selects the whole code span as soon as the second click lands.
- Copying text chosen inside inline code copies just that text, without the backticks or the list marker around it.
- Task checkboxes grow with the text when you zoom, and their check mark stays centred at any display scale.
- Windows shows a shorter file type name for Markdown files.

## 0.1.2

- The check mark in a ticked task checkbox now sits in the middle of the box instead of slightly to the right.

## 0.1.1

- Spell checking is now a setting, **Settings › Appearance › Spell Check**, and is off by default.
- The check mark in a ticked task checkbox is centred vertically.
- Release pages list which file to download for each system.

## 0.1.0

The first release of Markpad Live, a fork of Markpad with a WYSIWYG editor.

- Type in the rendered document, or switch to split view or Markdown source.
- Format with the toolbar or keyboard shortcuts, including tables and task lists.
- Markpad Live checks for updates when it starts and every six hours, and installs them from this page.
